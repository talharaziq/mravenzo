First-time setup

  1. Upload this project to a new GitHub repository.
  2. Connect that repository to Cloudflare Pages with npm run build as the build command and dist as the output folder.
  3. Open Pages CMS, install its GitHub App and choose your repository. It reads the field setup from .pages.yml.
  4. In Site settings, set the final website URL and contact email. Update the same domain in astro.config.mjs and public/robots.txt.

The content editor is hosted by Pages CMS. This page is a shortcut and setup guide; it does not store your GitHub credentials.
